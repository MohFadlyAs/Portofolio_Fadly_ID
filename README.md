# Portofolio Fadly

Personal portfolio built with Vite + React + TypeScript.

## Requirements
- Node.js (>=16)

## Run locally

1. Install dependencies

   npm install

2. Start development server

   npm run dev

3. Build for production

   npm run build

## Notes
- Environment variables: create an `.env.local` if needed and do not commit secrets.
- This repo is configured for Vite; see `vite.config.ts` and `package.json` scripts.
